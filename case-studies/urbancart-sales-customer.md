# UrbanCart Sales & Customer Analytics

**Focus:** e-commerce revenue, customer behavior, returns and delivery  
**Tools reported in resume:** Excel, SQL Server, T-SQL, Power BI, DAX  
**Evidence status:** This summary comes from Karan Mahalik's resume. Datasets, SQL scripts and Power BI source files are **not yet published in the accessible repositories**. Analysis and dashboards have not been independently reproduced.

## Business questions

- How did revenue change by month, quarter, year, channel and location?
- Which products ranked highest and how did sales compare across periods?
- What were order frequency, repeat-customer behavior and return patterns?
- How did payment methods and delivery metrics vary?

4. Analyzed order frequency, repeat customers, returns, payment methods and delivery metrics.
5. Built a two-page Power BI report with relationships, DAX, KPI cards and slicers.
