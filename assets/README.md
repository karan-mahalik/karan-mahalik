# Karan's organized profile assets

This directory uses the same layout pattern as Bhagabata Brahma's cleaned-up GitHub profile, adapted to Karan's verified projects and professional positioning.

- [branding/](branding/) — static hero and linked portfolio banner
- [projects/](projects/) — separately clickable source-repository cards and one clearly **planned** generative-AI lab card
- [diagrams/](diagrams/) — technical focus and illustrative analysis workflow

All visuals are static local SVGs with a consistent viewBox, generous padding and bounded icon area. GitHub renders them as images; their parent Markdown links provide the actual click actions.

These images are **illustrations**, not screenshots or verified analytical results. Keep technical details in README prose and case-study files. Do not put API keys, identifying data or unverified claims in the artwork.

See [visual design notes](../docs/VISUAL_DESIGN.md) and [profile README](../README.md).
